# 其他安排（占用日）实现计划

> **For agentic workers:** 实现时按 task 推进；纯函数优先 TDD（`node miniprogram/utils/*.test.js`）。先落盘 spec，再改代码。

**Goal:** 支持对某一天标记「其他安排」并写事由，防止复制上月/批量/随手新增把该日提前占满；需要时仍可「仍要约」强制写入。

**Architecture:** 独立集合 `day_holds`（`date` + `reason`），云函数 `dayHold`（`list|upsert|remove`）。月历与约课并行加载；写入闸门仅在客户端（云函数不硬拒）。占用不是课程：不进节数/支出/提醒，不随复制上月走，`bookingClearAll` 不清占用。

**Tech Stack:** 微信小程序 + 云开发；现有 `callFunction` / cache / `calendar-grid`；Node assert 单测。

**已锁定决策：**

- 约束强度 = 默认拦住，弹事由，点「仍要约」才写入
- 复制上月 / 批量 = 默认跳过，预览标事由，可勾回
- 已有课保留，占用只拦后续写入
- 范围 = 整本账本这一天（不按学员、不按时段）
- 数据 = 独立 `day_holds`，不用假课占坑
- 时间线 = 仅在「该日已有课」的组头下显示事由；不插入无课占用日
- 概览 = 不算占用

详见 [2026-08-18-day-hold-design.md](../specs/2026-08-18-day-hold-design.md)。
