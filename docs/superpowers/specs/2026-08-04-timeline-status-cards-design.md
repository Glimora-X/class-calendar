# 时间轴：状态色矮卡设计

**日期：** 2026-08-04  
**状态：** 已确认  
**范围：** 仅时间轴视图（方案 A）

## 1. 目标

让用户能快速浏览一个月课程履历：进度、状态、人员分布、时间节奏。

本轮只改**时间轴列表卡片与时间轴节点**的视觉与信息层级，不改月历格子、日列表卡片，也不做按状态/老师/学员的统计过滤（过滤另开一轮）。

## 2. 非目标

- 不改 `calendar-grid` 月历色点语义（仍可暂跟老师色）
- 不改月历展开日列表里的 `booking-item` 外观（继续用现有「老师色大卡」）
- 不引入老师真实头像上传/字段（无头像时用姓名首字）
- 不做状态/学员过滤 chips

## 3. 信息层级

视觉权重顺序：

1. **上课时间**（最大、状态色字）
2. **老师**（右侧：首字圆头像 + 姓名）
3. **学员 | 科目**（左侧小字辅助）
4. **状态角标**（卡片右上角斜向丝带；色权重高，不抢时间行宽度）

第二行空间布局（重要）：

- **左**：`学员 | 科目`
- **右**：老师头像（或首字）+ 老师名

一句话读法：「20:00 然泽给 Sisi2BJ 上英语，目前待上。」

约束：

- 卡面用浅底，**不做**大块实色填满（参考图：白/浅色为主 + 状态色强调）
- **已退不用红色**（退课是状态，不是错误/警告）
- 已退不使用删除线、不降透明度（避免可读性变差）

状态文案沿用现有：`待上` / `已上` / `已转` / `已退`（`utils/booking-status.js`）。

## 5. 卡片布局

```
┌──────────────────────────────────┐  ~80px
│ 20:00 — 20:25              ╱待上╱ │  时间 + 右上斜角标
│                                  │
│  Sisi2BJ | 英语        ◉ 然泽   │  左：学员|科目  右：老师
└──────────────────────────────────┘
```

规格（设计 px → 小程序约 ×2 为 rpx）：

| 元素 | 规格 |
|------|------|
| 卡片高度 | 76–82px（约 152–164rpx） |
| 卡片圆角 | 与现时间轴风格接近，约 12–14px；`overflow: hidden` 裁切斜标 |
| 卡间距 | 8px |
| 日期组间距 | 18–24px |
| 时间 | ~18px / 600；`HH:mm — HH:mm`；无时钟 icon；颜色按状态表 |
| 状态角标 | **卡片右上角斜向丝带**（约 45°），白字，状态色底；不占用时间行横向空间 |
| 第二行 | flex：左 `学员 | 科目`（可省略溢出），右老师区右对齐 |
| 老师头像 | 24×24 圆；无真实头像时用姓名首字；在老师名左侧 |
| 老师名 | ~14px / 500；主文字色按状态表 |
| 学员\|科目 | ~12px / 400；辅助色按状态表；中间用 ` | ` |

交互：整卡点击仍进入约课详情/编辑（与现一致）。`···` 是否保留：本轮**可隐藏**（信息密度优先；改/删仍进详情页）。若后续要快速改状态再加菜单。

## 6. 时间轴节点

- 每个日期组左侧竖线 + 圆点结构保留
- **圆点颜色**改为该日**第一节课（或组内代表课）的 resolved status 色**（见上表节点列）
  - 推荐：取该日列表中时间最早的一节课状态色，与「扫一眼进度」一致
- 竖线可用浅中性灰/浅蓝，不强绑状态（避免多状态日竖线花）

日期列（大号日 + 星期）保持，不占用卡片高度预算。

## 7. 实现边界（建议）

为避免月历日列表被连带改样：

1. **新建**时间轴专用卡片组件，例如 `timeline-booking-card`；或给 `booking-item` 增加 `variant="timeline"`，默认仍为旧样式。
2. `timeline-list` 改用新 variant/组件；传入 `status`（resolved）而非仅 `statusLabel`，以便上色。
3. 在 `booking-status.js`（或日历页映射层）增加 `statusVisual(status)`，集中返回 class / token，避免四散硬编码。
4. `pages/calendar` 组装 timeline `groups` 时：
   - 每条 booking：`resolvedStatus`、`statusLabel`、首字 `teacherInitial`
   - 每组：`dotStatus` / `dotColorClass` 取组内最早课状态
5. **去掉**时间轴卡片上的老师色 `cardTone` 渐变依赖（时间轴不再用老师色填卡）。

数据：状态仍由现有 `resolveBookingStatus` 计算；无新云字段。
