# 其他安排（占用日）设计说明

**日期：** 2026-08-18  
**状态：** 已确认  
**范围：** 独立占用日实体、月历标注、写入闸门（新增/改期/复制上月/批量）

---

## 1. 目标

支持对某一天标记「其他安排」并写明事由，防止复制上月、批量新增或随手加点把该日提前占满。需要时仍可「仍要约」强制写入。

---

## 2. 已确认决策

| 项 | 选择 |
|----|------|
| 约束强度 | 默认拦住，弹出事由，点「仍要约」才写入 |
| 复制上月 / 批量 | 默认跳过，预览标事由，可勾回 |
| 已有课 | 保留；占用只拦后续写入 |
| 范围 | 整本账本这一天（不按学员、不按时段） |
| 数据 | 独立集合 `day_holds`，不用假课占坑 |
| 写入校验 | 客户端闸门；云函数不硬拒 |
| 时间线 | 仅在「该日已有课」的组头下显示事由；不插入无课占用日 |
| 概览 | 不算占用；不触发课前提醒 |
| 清空课程 | `bookingClearAll` 不清占用 |

---

## 3. 数据模型

集合 `day_holds`（权限：仅创建者可读写）

| 字段 | 规则 |
|------|------|
| `date` | `YYYY-MM-DD`，同一用户同一天最多一条 |
| `reason` | 必填，去空格后 1–20 字 |
| `_openid` / `createdAt` / `updatedAt` | 与现有记录一致 |

索引：`_openid` + `date`。

云函数 `dayHold`，`action: list | upsert | remove`。

占用不是课程：不进节数/支出/提醒，不随「复制上月」走。

---

## 4. 界面

### 4.1 月历格子

- `is-hold`：淡底 + 日期旁小「事」
- 有课：色点 /「N节」照旧
- 学员/老师筛选不隐藏占用标记
- 完整事由只在日详情展示

### 4.2 日详情

有占用：轻横幅 — 标题「这天有其他安排」、事由、「最好别再约」、改事由 / 取消标记。

无占用：操作区增加「其他安排」；就地输入 1–20 字，不新开页。

无课 + 有占用：空状态「这天有事，最好别约」（不用「这天还空着」）。

### 4.3 时间线 / 概览

时间线：有课的日期组头下附事由一行。  
概览：不统计占用。

---

## 5. 写入闸门

- **新增 / 改期**：目标日有占用 → 弹窗确认「仍要约」；多草稿多占用日汇总弹一次；只改时间不改日期不弹
- **复制上月**：目标日在占用日 → 仍在「可生成」，默认不勾选，副文案带事由
- **批量按星期**：预览标占用日默认不选；提交只写选中日

---

## 6. 用词

| 概念 | 用词 |
|------|------|
| 实体 | 其他安排 |
| 标记入口 | 其他安排 / 标记其他安排 |
| 提示 | 这天有事 / 最好别再约 |
| 强制写入 | 仍要约 |

---

## 7. 明确不做

按学员占用、时段占用、重复规则、日期区间批量标记、云函数硬拒、时间线插入无课占用日、占用进概览、长按格子 / FAB 标记入口。
