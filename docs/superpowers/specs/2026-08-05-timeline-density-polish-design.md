# 时间轴：密度精修（压卡高 + 弱角标 + 骨架强化）

**日期：** 2026-08-05  
**状态：** 已确认  
**范围：** 仅时间轴视图视觉精修（方案 A）  
**前置：** `docs/superpowers/specs/2026-08-04-timeline-status-cards-design.md`

## 1. 目标

在上一版「状态色矮卡」方向正确的基础上，把时间轴从「好看的课程卡片列表」压成更高效的**月度课程履历浏览器**：

- 一屏可见课程从约 4–5 节提升到约 6–7 节
- 信息扫读顺序稳定为：**时间 → 老师 → 学员/学科 → 状态**
- 状态角标不再抢过时间的第一视觉权重
- 时间轴竖线/节点成为可读骨架，而不是背景装饰
- 今天有轻量锚点，滚动时不丢当前位置

## 2. 非目标

- **不做**状态 / 学员 / 老师双行筛选重构（过滤另开一轮）
- 不改 `filter-chips` 现有老师筛选行为
- 不改 `calendar-grid` 月历格子
- 不改月历展开日列表 `booking-item`
- 不把斜切丝带改成胶囊角标
- 不把节点改成「圆环 + 中心小圆点」`⊙`（保持现有空心圆）
- 不缩短星期文案（仍用「星期六」，不用「六」）
- 不引入老师真实头像新字段（有 URL 用图，无则首字圆，与现一致）

## 3. 信息层级（最终）

| 层级 | 内容 | 规格 |
|------|------|------|
| 1 | 上课时间 `HH:mm — HH:mm` | ~18px / 600；颜色跟状态 |
| 2 | 学员 \| 学科 | ~13px / 500；`#344054` 量级（可按态微调，保持辅助感） |
| 3 | 老师（首字圆/头像 + 姓名） | ~13px / 500；右侧；**不显示「老师」二字** |
| 4 | 状态 | 右上斜切丝带；用颜色表达，字号缩小，不抢时间行 |

扫读一句话：「13:00 → 乔姐 → Sisi2BJ \| 英语 → 已上」

## 4. 状态色表

沿用上一版四态 token，本轮**不换色**：

| 状态 | 卡面底色 | 角标底色 | 时间色 | 节点边框色 |
|------|----------|----------|--------|------------|
| 待上 `pending` | `#F0F6FF` | `#3B82F6` | `#2563EB` | `#3B82F6` |
| 已上 `done` | `#F3F7F5` | `#52A878` | `#438A62` | `#52A878` |
| 已转 `transferred` | `#F7F3FF` | `#8B5CF6` | `#7C4DDB` | `#8B5CF6` |
| 已退 `refunded` | `#F6F7F8` | `#9AA1AA` | `#7B8490` | `#9AA1AA` |

已退不用红、不用删除线、不降透明度。

## 5. 卡片布局

```
┌─────────────────────────────╲
│ 13:00 — 13:25               ╲  斜切丝带（缩小约 30%）
│                              │
│ Sisi2BJ | 英语        ◉乔姐  │
└──────────────────────────────┘
        高度目标 88–96px
```

规格（设计 px → 小程序约 ×2 为 rpx）：

| 元素 | 规格 |
|------|------|
| 卡片高度 | **视觉约 88–96px**；相对现状压紧（减 padding / gap，取消 `space-between` 撑开）；`min-height` 以贴合内容为准，避免虚高 |
| 内边距 | 上下左右收紧（建议约 12–14px 量级） |
| 行间距 | 时间行与 meta 行更贴（建议 gap ~6–8px） |
| 时间 | ~18px / 600；无时钟 icon |
| 状态角标 | **保留斜切丝带**；整体约缩小 30%（宽/高/字号/右偏移同步缩）；白字；状态色底；`overflow: hidden` 裁切 |
| 第二行左 | `学员 \| 科目`；溢出省略 |
| 第二行右 | 头像/首字圆 + 老师名；右对齐；无「老师」文案 |
| 老师头像 | ~22–24px 圆；有 `teacherAvatarUrl` 用图，否则首字 |
| 卡间距 | 约 6–8px |

交互：整卡点击进编辑，与现一致。

## 6. 日期列

保持：

```
01
星期六
```

- 日号：约 20px / 700
- 星期：仍为「星期日…星期六」三字全称；约 11px / 400；浅灰（如 `#8B95A5`）
- **不**改成「六」

## 7. 时间轴骨架

| 元素 | 规格 |
|------|------|
| 竖线 | `#CBD5E1`（加深，成为阅读骨架） |
| 节点 | **保持现有空心圆**（白底 + 状态色边框）；**不**改成圆环套实心点 |
| 节点色 | 仍取该日最早一节课的 resolved status 色（见色表） |

## 8. 今天锚点

当某日期组的 `date === 今天(YYYY-MM-DD)` 时，在日期列星期下方增加第三行：

```
05
星期六
今天
```

约束：

- 「今天」文案色约 `#94A3B8`，~11px / 400
- **不做**大色块、整行高亮背景、粗边框
- 仅时间轴；月历格子 today 样式不动

`timelineGroups` 组装时增加 `isToday: boolean` 供 wxml 判断。

## 9. 实现边界

主要改动面：

1. `components/timeline-booking-card` — 压高、缩丝带、收紧间距；结构可不改
2. `components/timeline-list` — 日期字号、竖线色、今天标记；节点形态不改
3. `pages/calendar/index.js` — `timelineGroups` 补 `isToday`；星期文案保持 `WEEKDAY_CN` 全称

不改：`booking-item`、`filter-chips`、`booking-status` 色表（除非为 today 辅助无必要）、云函数。

## 10. 验收标准

- [ ] 时间轴卡片视觉高度约 88–96px 量级；一屏课程明显多于改版前本轮
- [ ] 斜切丝带仍在，但体积约缩小 30%，不再明显压过时间权重
- [ ] 第二行仍为左 `学员|科目`、右老师；无「老师」二字
- [ ] 日期仍为「01 / 星期六」，非「六」
- [ ] 竖线为 `#CBD5E1`；节点仍为空心圆 + 状态色边框
- [ ] 今天日期组有轻量「今天」提示，无大色块
- [ ] 老师筛选 chips、月历、日列表外观与行为不变
- [ ] 点击卡片仍可进入编辑
