# 学员过滤与青春跳脱 UI 方向

**日期：** 2026-08-06  
**状态：** 已确认（实现中）  
**范围：** 信息架构微调、日历/概览筛选、全站交互与视觉方向

---

## 1. 目标

在不大改数据模型的前提下：

1. **查询侧**支持按学员（孩子）过滤，默认看全部
2. **写入侧**仍可选任意学员（联想匹配），不锁死「当前孩子」
3. 全站 UI 往**青春、活力、跳脱**收束：靠色、圆、短动效、插画，不靠信息变吵

日历色点语义**不变**：点 = 老师。

---

## 2. 已确认决策

| 项 | 选择 |
|----|------|
| 默认视图 | **全部学员**（不是强制「当前默认孩子」） |
| 学员角色 | **筛选维度**，不是全局强制身份 / 不是 Tab |
| 单学员 | **隐藏**学员过滤条，避免无意义噪音 |
| 多学员 | 显示：`全部` + 各学员胶囊 |
| 新增/编辑 | 可给**任意**学员约课；名单联想匹配；若当前正按某学员筛选，可预填但仍可改 |
| 日历色点 | **仍按老师**（`cardTone` / `teacherColorMap`）；图例仍是老师 |
| 老师筛选 | 保留；与学员筛选分层，不混成一种 chip |
| 顶栏 | 不做每页大 Greeting Header；不做「小主人」强绑定 |
| 视觉跳脱 | 色、圆、短动效、插画；禁止靠堆文案/堆标签制造热闹 |

---

## 3. 信息架构

```
家长账号
 └── 约课（默认同屏看全部学员）
      ├── 筛选：学员（可选，仅多孩显示）
      ├── 筛选：老师（已有）
      └── 单条约课仍含 studentName
```

- **读**：日历 / 时间线 / 概览 / 列表 → 可按学员滤，或全部
- **写**：新增 / 批量 / 编辑 → 学员字段自由选择

不引入「必须先选当前孩子才能操作」的流程。

---

## 4. 交互

### 4.1 学员过滤条

**出现条件：** `name_lists.students.length >= 2` 才渲染。

**位置：**

- 日历：`month-nav` 下方，学员条在上、老师条在下
- 概览：周期选择附近，与周期 chips 视觉区分

**行为：** 默认全部；点某学员只看该学员；与老师筛选叠加；本地记忆上次筛选，名单中不存在时回退全部。

### 4.2 新增 / 编辑

保持联想输入；多学员时增加横向快捷点选；可接受 `studentName` query 预填。

### 4.3 明确不做

- 底部 Tab 放孩子名
- 每页强制大头像问候头
- 色点改成孩子维度
- 切学员整页强换肤

---

## 5. UI / 视觉方向

### 5.1 「跳脱」四要素

| 要素 | 用法 |
|------|------|
| **色** | 品牌蓝 + 点缀黄；老师色点保留；学员胶囊柔和区分 |
| **圆** | 大圆角胶囊、圆形快捷选、柔和 FAB |
| **短动效** | 胶囊选中 120–160ms；列表淡入；空状态轻晃 |
| **插画** | 空状态、概览 hero 气氛，不抢主任务 |

### 5.2 反模式

信息变吵、Emoji 堆砌、霓虹描边、小点同时表示老师又表示孩子。

---

## 6. 数据 / 实现

本阶段按 `studentName` 客户端过滤，不改云函数与 booking schema。色点逻辑不改 `calendar-marks`。

---

## 7. 非目标

- 强制全局「当前孩子」身份
- 孩子主题色整页换肤
- `studentId` 迁移
- 全家复杂对比报表

---

## 8. 验收

1. 仅 1 个学员时看不到学员过滤条
2. ≥2 个学员可见「全部 + 各学员」；默认全部；可与老师筛选叠加
3. 色点与图例仍对老师
4. 筛选后新增可预填且可改
5. 相关单测通过
